# Архитектура

Приложение разделено на UI, доменную модель, сканер, метаданные, классификаторы, SQLite и сортировку. `app/ai/base.py` является стабильным контрактом провайдера: UI и анализатор не должны импортировать SDK конкретного поставщика.

## Режимы

- Local: текущий rule-based baseline; API не вызывается.
- Cloud: один запрос на изображение через выбранный провайдер.
- Hybrid: локальная оценка, облако только для confidence ниже 0.60.

Секреты идут напрямую от компьютера пользователя к выбранному провайдеру. Файл `ai_settings.json` содержит только несекретные настройки, а ключ хранится в Windows Credential Manager через `keyring`.

## Контроль данных

Сортировка по умолчанию копирует файлы. Облачная отправка требует отдельного подтверждения в GUI. Ошибки провайдера не приводят к перемещению файла.
