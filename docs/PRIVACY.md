# Конфиденциальность

Локальный режим не отправляет изображения или метаданные в интернет. В облачном и гибридном режимах выбранные изображения отправляются напрямую выбранному провайдеру. Перед включением проверьте его условия хранения и обработки данных.

API-ключ не записывается в SQLite, логи, JSON или репозиторий. При отсутствии рабочего системного хранилища ключ не сохраняется. Сами изображения, кэш моделей, результаты сортировки и локальная база исключены из Git через `.gitignore`.
