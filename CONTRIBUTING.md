# Участие в разработке

1. Создайте fork и отдельную ветку.
2. Работайте только с тестовыми изображениями, не добавляйте личные фотографии, ключи или базы данных.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Перед PR запустите `python -m compileall -q main.py app tests` и `python -m unittest discover -s tests`.
5. Для изменений AI-провайдеров добавьте тесты с моками HTTP; реальные API-вызовы в CI запрещены.
6. Обновите `CHANGELOG.md`, если изменение заметно пользователю.

Соблюдайте типизацию, небольшие модули и принцип «ошибка лучше, чем риск потери данных». Не логируйте API-ключи, изображения и содержимое OCR.
