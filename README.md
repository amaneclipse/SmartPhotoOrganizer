# 📸 Smart Photo Organizer

Умная сортировка фотографий по категориям с помощью локального rule-based и облачного ИИ: Google Gemini или OpenRouter.

> Проект находится в рабочем MVP-статусе. Перед обработкой большой коллекции проверьте настройки на копии нескольких фотографий.

## ✨ Возможности

- 🧠 Локальный режим без API-ключа и облачный анализ через Gemini/OpenRouter.
- 🆓 Поддержка бесплатных API Google Gemini и OpenRouter.
- 🔒 Безопасное сжатие перед отправкой: максимум 512 px по длинной стороне, JPEG quality 50; оригинал не изменяется.
- ⚡ Пакетная параллельная обработка с настраиваемым количеством запросов.
- 📊 Учет лимитов бюджета, количества изображений и запросов.
- 📁 Умное копирование без перезаписи дубликатов.
- 💾 SQLite-кэш: уже скопированные фото не анализируются повторно, а неудачное копирование можно повторить без нового запроса к ИИ.

## 🔐 Приватность и безопасность

**В Облачном режиме фотографии сжимаются, но всё равно отправляются на сторонние серверы Google или OpenRouter.** Для строго приватных, секретных или чувствительных фотографий используйте Локальный режим.

API-ключи хранятся через `keyring` в Windows Credential Manager и не записываются в SQLite, JSON или Git. Перед использованием облачного API изучите актуальные условия хранения и обработки данных выбранного провайдера.

## 🚀 Установка

```bash
git clone https://github.com/amaneclipse/SmartPhotoOrganizer.git
cd SmartPhotoOrganizer
python -m venv .venv
```

Активируйте окружение:

```powershell
# Windows PowerShell
.\.venv\Scripts\activate
```

```bash
# Linux / macOS
source .venv/bin/activate
```

Установите зависимости и запустите приложение:

```bash
pip install -r requirements.txt
python main.py
```

## ☁️ Настройка облачного API

### Google Gemini

1. Откройте [Google AI Studio](https://aistudio.google.com/) и создайте API-ключ.
2. В настройках ИИ выберите **Google Gemini**.
3. Укажите vision-модель, например `gemini-2.5-flash`.
4. Оставьте Base URL пустым, вставьте ключ и сохраните настройки.

Для бесплатного тарифа ориентируйтесь на лимит **15 запросов в минуту** и установите небольшое значение «Параллельные запросы». Лимиты и доступность моделей меняются — проверяйте актуальную квоту в [документации Gemini](https://ai.google.dev/gemini-api/docs/rate-limits).

### OpenRouter

1. Создайте ключ на странице [OpenRouter](https://openrouter.ai/keys).
2. Выберите тип **OpenAI / Compatible (OpenRouter)** и провайдера `openai-compatible`.
3. Укажите Base URL: `https://openrouter.ai/api/v1`.
4. Выберите совместимую vision-модель с суффиксом `:free` из [каталога бесплатных моделей](https://openrouter.ai/collections/free-models).
5. Вставьте ключ и сохраните настройки.

Бесплатные модели OpenRouter имеют собственные ограничения частоты и дневного использования; популярные модели могут дополнительно ограничиваться upstream-провайдером.
