# Smart Photo Organizer

SmartPhotoOrganizer сканирует папки с изображениями, классифицирует фотографии и готовит безопасный план копирования по категориям. Оригиналы не изменяются: по умолчанию выполняется копирование.

## Текущий статус

Программа работает в двух основных режимах:

- **Локальный** — базовая классификация без отправки фотографий в интернет и без API-ключа.
- **Облачный** — анализ через **Google Gemini** или OpenAI-compatible API, включая **OpenRouter**. В интерфейсе также доступен гибридный сценарий, где облачный анализ используется для низкоуверенных локальных результатов.

Реализованы сжатие изображения перед отправкой, пул параллельных запросов, пакетная обработка, несколько API-ключей, SQLite-кэш, пропуск уже скопированных результатов, восстановление результатов, которые ещё не были скопированы, и сброс кэша БД.

Текущий набор тестов проходит: `23 passed`.

## Внимание: приватность

При использовании **Облачного** или гибридного режима фотографии отправляются на сторонние серверы выбранного провайдера. Не используйте этот режим для секретных, личных или чувствительных фотографий без необходимого согласия и проверки условий обработки данных провайдера.

Перед отправкой приложение уменьшает изображение до максимальной стороны 512 пикселей и отправляет JPEG-копию с качеством 50. Оригинальный файл на диске не изменяется.

## Быстрый запуск

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Для разработки рекомендуется Python 3.12 или новее, если он совместим с установленными зависимостями. API-ключи сохраняются только в Windows Credential Manager через `keyring`, а не в SQLite, JSON или Git.

## Бесплатный Google Gemini

1. Откройте [Google AI Studio](https://aistudio.google.com/) и создайте API-ключ.
2. В настройках приложения выберите тип провайдера **Google Gemini**.
3. Укажите модель, например `gemini-2.5-flash`.
4. Оставьте Base URL пустым: native Gemini API использует прямой endpoint Google.
5. Вставьте ключ и сохраните настройки.

Для бесплатного тарифа ориентируйтесь на лимит **15 запросов в минуту** для доступной вашему проекту модели: установите «Параллельные запросы» ниже лимита, например 5–10, и проверьте актуальные квоты в Google AI Studio. Бесплатный тариф и доступность моделей могут меняться; данные о текущих ограничениях публикует [документация Gemini API](https://ai.google.dev/gemini-api/docs/rate-limits).

## Бесплатный OpenRouter

1. Создайте ключ на странице [OpenRouter API Keys](https://openrouter.ai/keys).
2. Выберите тип провайдера **OpenAI / Compatible (OpenRouter)**.
3. Выберите провайдера `openai-compatible`.
4. Укажите Base URL: `https://openrouter.ai/api/v1`.
5. Укажите бесплатную модель с суффиксом `:free`, например актуальную vision-модель из [каталога бесплатных моделей OpenRouter](https://openrouter.ai/collections/free-models).
6. Вставьте ключ и сохраните настройки.

У бесплатных вариантов OpenRouter есть ограничения по частоте и дневному числу запросов; популярные модели могут дополнительно ограничиваться upstream-провайдером. Проверяйте актуальные лимиты в [документации OpenRouter](https://openrouter.ai/docs/guides/routing/routers) и настройках аккаунта.

## Работа с фотографиями

1. Выберите исходную папку.
2. Выберите папку назначения.
3. Нажмите **Сканировать и анализировать**.
4. Проверьте результаты и при необходимости используйте предварительный просмотр.
5. Нажмите **Начать копирование**.

Успешно скопированные файлы отмечаются в SQLite-кэше и не анализируются повторно. Если анализ выполнен, но копирование не удалось, результат берётся из кэша и снова предлагается для копирования без нового запроса к AI. Кнопка **Сбросить кэш (БД)** удаляет историю анализа и операций, но не удаляет уже существующие файлы.

## Ограничения текущей версии

- Нужны интернет-соединение и собственный API-ключ для облачного режима.
- Ограничения бесплатных тарифов, список моделей, цены и политики хранения данных принадлежат провайдерам и могут измениться.
- Не все модели поддерживают изображения или JSON-ответы; при ошибке провайдера выберите совместимую vision-модель.
- Локальный режим использует базовую классификацию и не скачивает нейросетевые модели автоматически.
