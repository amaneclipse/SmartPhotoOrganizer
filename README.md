# Smart Photo Organizer

Windows-программа для локального анализа и безопасной сортировки изображений. Оригиналы по умолчанию не удаляются и не изменяются: приложение сначала показывает результат, а затем копирует файлы в выбранную структуру.

## Возможности

- рекурсивное сканирование JPG, PNG, WEBP, TIFF, HEIC/HEIF, GIF, AVIF и популярных RAW-расширений;
- EXIF, размеры, ориентация и приоритетная детекция скриншотов;
- категории, источники, `На проверку`, SQLite-кэш и журнал;
- локальный, облачный и гибридный режимы;
- OpenAI Responses API и OpenAI-compatible API через общий интерфейс `AIProvider`;
- API-ключи только в Windows Credential Manager через `keyring`;
- ограничение количества изображений/запросов, rate limit и подтверждение облачной отправки;
- предварительный просмотр и collision-safe копирование;
- PyInstaller-сборка и GitHub Actions.

Нейросетевые локальные модели и OCR не скачиваются автоматически. Текущий локальный baseline работает без API-ключа; расширение ONNX/CLIP/OCR подключается отдельными адаптерами.

## Системные требования

- Windows 10/11 x64;
- для исходников: Python 3.12+ и 2–4 ГБ свободного места;
- для EXE: Python не нужен конечному пользователю;
- облачный режим требует собственного ключа выбранного провайдера и интернет-соединения.

## Быстрый запуск из исходников

1. Установите Python с официального сайта `https://www.python.org/downloads/`. В установщике отметьте **Add Python to PATH**.
2. Скачайте ZIP репозитория или выполните `git clone`.
3. Откройте папку проекта в PyCharm.
4. Создайте окружение:

```powershell
python -m venv .venv
```

5. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

6. Запустите:

```powershell
python main.py
```

Если `python` не найден, используйте `py -3.12` или полный путь к `python.exe`. В PyCharm откройте **Settings → Project → Python Interpreter**, выберите `.venv\Scripts\python.exe`, затем запустите `main.py` зелёной кнопкой.

## Готовый EXE

Скачайте ZIP из GitHub **Releases**, распакуйте его и запустите `SmartPhotoOrganizer.exe`. Python и зависимости не нужны. Для разработчика сборка выполняется командой `build_windows.bat`; подробности находятся в [docs/RELEASE.md](docs/RELEASE.md). Локальные модели в EXE не включаются.

## Настройка AI

Откройте **Настройки → Искусственный интеллект**.

1. Выберите режим: **Локальный**, **Облачный** или **Гибридный**.
2. Для облачного режима выберите `openai` или `openai-compatible`, укажите модель и Base URL.
3. Получите собственный API-ключ в кабинете выбранного провайдера.
4. Введите ключ в поле, нажмите **Проверить подключение**, затем **Сохранить настройки**.
5. Ключ скрыт символами и сохраняется только в Windows Credential Manager. Если `keyring` или системное хранилище недоступны, приложение откажется сохранять ключ.
6. Кнопка **Удалить ключ** удаляет его из защищённого хранилища.

Ключи не встраиваются в программу, не сохраняются в SQLite, JSON, логах или Git. Не добавляйте реальные ключи в `.env`; файл `.env.example` содержит только пример переменных.

При облачном режиме изображения отправляются выбранному провайдеру. Проверьте его условия обработки данных и конфиденциальности. Документы с чувствительными данными рекомендуется анализировать только локально.

Настройте максимальное число изображений, запросов, размер изображения и необязательный бюджет. Если провайдер не предоставляет цены, приложение не показывает выдуманную стоимость.

## Сортировка

1. Выберите исходную папку.
2. Выберите папку назначения.
3. Нажмите **Сканировать и анализировать**.
4. Проверьте таблицу и нажмите **Предварительный просмотр**.
5. Низкоуверенные результаты попадут в `На проверку`.
6. Нажмите **Начать копирование** и подтвердите операцию.

Папки создаются автоматически. При совпадении имени добавляется суффикс `(1)`, `(2)` и т. д. Перемещение оригиналов в текущем UI не используется по умолчанию; безопасный режим — копирование. База `organizer.sqlite3` и настройки являются локальными файлами и исключены из Git.

## Дубликаты и ручная проверка

В текущем MVP обнаружение SHA-256/pHash-дубликатов и редактор ручной коррекции находятся в следующем этапе разработки. Не удаляйте файлы автоматически. До включения этого этапа используйте внешнюю резервную копию и проверяйте папку `На проверку` вручную.

## Обновление и удаление

Для исходников скачайте новую версию и повторно выполните установку зависимостей. Для EXE скачайте новый архив из Releases. Удаление программы — удаление распакованной папки; отдельно удалите `organizer.sqlite3`, `ai_settings.json` и результаты сортировки, если они больше не нужны.

Для удаления локальных моделей удалите выбранную пользователем папку `models/` или `model_cache/`. Для удаления ключа используйте кнопку **Удалить ключ**; это безопаснее ручного удаления системных записей.

## Распространённые ошибки

- **PySide6 не установлен** — выполните `python -m pip install -r requirements.txt`.
- **Python не найден** — установите Python, отметьте Add to PATH или используйте `py -3.12`.
- **Credential Manager недоступен** — установите `keyring` в окружение и проверьте Windows Credential Manager; приложение не сохранит ключ в открытом виде.
- **Ошибка API** — проверьте ключ, модель, Base URL, интернет и лимиты аккаунта; повторите проверку подключения.
- **Файл не читается** — проверьте права доступа и формат; исходник не перемещается при ошибке.
- **Недостаточно места** — выберите другую папку назначения и не удаляйте оригиналы до проверки результата.

## Частые вопросы

**Нужен ли интернет?** Нет для локального режима; да для облачного.

**Можно ли использовать общий ключ?** Нет. Каждый пользователь вводит собственный ключ.

**Отправляются ли фотографии автоматически?** Нет. Облачный/гибридный режим включается пользователем и подтверждается перед анализом.

**Удаляются ли оригиналы?** Нет, по умолчанию выполняется копирование.

**Можно ли добавить другого провайдера?** Да, реализуйте `AIProvider` из `app/ai/base.py` и зарегистрируйте его в `AIManager`.
